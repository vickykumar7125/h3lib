# Examples

Runnable scripts in the repository:

```bash
python examples/basic_usage.py
python examples/duckdb_usage.py
python examples/redis_cache_usage.py
python examples/postgres_extensions.py
python examples/index_modes_usage.py
python examples/analytics_usage.py
```

| Script | Demonstrates |
|--------|----------------|
| `basic_usage.py` | SQLite put/get/disk/polygon |
| `duckdb_usage.py` | DuckDB + H3 extension status |
| `redis_cache_usage.py` | Redis cache wiring |
| `postgres_extensions.py` | PostGIS / h3-pg status messages |
| `index_modes_usage.py` | Cell / edge / vertex / topology |
| `analytics_usage.py` | Aggregate + smooth without pandas |
