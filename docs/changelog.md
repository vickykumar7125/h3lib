# Changelog

## 0.1.0

Initial public release.

- Pluggable stores: SQLite, DuckDB, Postgres (PostGIS + h3-pg), MySQL, MongoDB
- Optional Redis / in-memory cache
- Index modes: `h3_index`, `cell`, `directed_edge`, `vertex`
- Hierarchy, traversal, measures, analytics helpers
- Docker Compose integration stack
- CI on Ubuntu / macOS / Windows × Python 3.10–3.14
- Docs site: https://vickykumar7125.github.io/h3lib/
